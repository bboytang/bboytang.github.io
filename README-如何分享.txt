云也 YUNYE 女装店移动端交互原型（演示）
=======================================

1. 直接查看：打开 index.html，手机和电脑浏览器均可查看。
2. 给他人转发：可以直接发送 yunye_mobile_demo.html 文件；对方需用支持本地 HTML 的浏览器打开。部分社交平台内置预览不能运行 JavaScript。
3. 最方便的分享方式：解压 ZIP 取得 index.html，并将其部署到静态网页托管平台（如 GitHub Pages、Netlify），获取 https://... 网页链接后发给别人。若使用 Netlify 的手动上传，请上传解压后的文件夹。
4. 示例条码：
   供应商原码：6901234567892
   云也自有条码：YY1-00000001
   未绑定条码：YY1-00000999
5. 支持体验：商品分类搜索、新增商品及自动内部编码、绑定原条码、扫码查询价格库存、模拟采购入库与销售、单据记录、店员店长权限。
6. 重要说明：本文件没有连接真实数据库/相机/支付系统；数据仅保存在当前浏览器 localStorage，不会与其他手机同步。预览内的条码、金额及库存均为虚构演示数据。
7. 本网页完全独立，不依赖外部 CDN、图片或在线接口。
